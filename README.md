# Minecraft_Liangfeng_highschool_save
<img width="3840" height="2160" alt="MCLF_cover" src="https://github.com/user-attachments/assets/0833faca-edd0-4588-8f5e-b00d69e2809d" />

这个是Minecraft梁丰高中的存档，B站过来的小伙伴可以下载.

存档文件是MCLF2025.zip，你只需要下载它，然后把zip文件进行解压，解压出来的名字应该还是MCLF2025,然后，把整个文件夹全部移到Minecraft一个具体版本游戏的saves存档文件夹即可。

如果你会用github，那我不多介绍了，你不熟悉github的话，可以直接点击仓库里的MCLF2025.zip，然后右边会直接出现一个类似下载的按钮，直接点击就可以下载了。
<img width="234" height="44" alt="image" src="https://github.com/user-attachments/assets/34a5b33c-6686-4191-8358-e7ea606ac4b8" />

请注意，请使用Minecraft 1.21.x及以上版本打开，如果用低版本，我不保证所有方块都能正常加载。本存档里面用到的所有建筑材料都是原版方块，无需加载任何mod.如果进一步，你希望获得我视频里的效果，首先确保你有高配显卡的电脑，然后，你需要安装必备的光影依赖项(我使用的是fabric, 应该会需要fabric， Iris, 以及Sodium)，然后安装photon光影和Distant Horizons遥远的地平线mod.你可以去CurseForge上去找mod,不过我更推荐使用正版账号+PCL/HMCL启动器游玩，因为它们配置Minecraft版本，mod,光影，材质很方便。

本存档不提供百度网盘，QQ群文件，文档等链接，github是我唯一放置本存档的地方。
